# Evidence folder

Place original, genuine screenshots and supporting images here after completing the corresponding lab exercise. Follow the filename suggestions in [Portfolio Evidence Plan](../Portfolio%20Evidence%20Plan.md).

Before publishing, review every image for usernames, credentials, tokens, personal information, public IP addresses, device serial numbers and unrelated desktop content. Do not fabricate or recreate tool output. Pair each important screenshot with a short explanation in the relevant technical note.

This directory intentionally contains no screenshots yet; capture evidence from the live lab when the exercise is repeated.
