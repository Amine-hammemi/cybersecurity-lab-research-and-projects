# Provisioning

Provisioning is the process of preparing IT resources and making them available to systems or users. Depending on the context, those resources can include servers, networks, applications, accounts, storage and permissions.

## 1. Server provisioning

Server provisioning prepares a physical or virtual server for a defined role.

Examples of server roles:
- File server
- Web server
- Application server
- Proxy server
- Policy server

Typical tasks include:
- Defining the server's purpose and resource requirements.
- Allocating CPU, RAM and storage.
- Installing and configuring the operating system.
- Installing the required services and applications.
- Applying access controls and baseline security settings.
- Testing that the server is ready for use.

## 2. Network provisioning

Network provisioning prepares the network components and configuration needed for devices and services to communicate.

Typical tasks include:
- Configuring routers, switches, firewalls and network segments.
- Assigning IP addresses and defining routing.
- Configuring DNS and DHCP where required.
- Defining which devices and identities can access network resources.
- Applying and validating network security controls.

## 3. Application provisioning

Application provisioning makes an application ready to run in its target environment.

This can include:
- Installing the application and its dependencies.
- Creating required accounts or service identities.
- Applying configuration and permissions.
- Allocating runtime resources.
- Verifying that the application starts and works as expected.
